# Humo AI Bot

A Telegram bot that answers users' questions, generates images, and generates videos using AI.

## Features
- Answers questions in chat
- Image generation
- Video generation

## Setup
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Set your Telegram bot token and API keys as environment variables
4. Run: `python main.py`

## Status
Early-stage project, under active development.
